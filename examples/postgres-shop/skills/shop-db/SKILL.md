# shop database

Sample online shop with customers, products, orders and order items.

Read-only access to a PostgreSQL database through the `shop` MCP server generated by apitame.

## Tools

| Tool | Use it to |
| --- | --- |
| `list_tables` | See every table and view (with row estimates on PostgreSQL). |
| `describe_table` | Get columns, keys and indexes before writing SQL. |
| `query` | Run one SELECT. At most 200 rows come back. |
| `top_customers` | Customers ranked by total spent on paid and shipped orders |
| `orders_for_customer` | Recent orders of one customer, newest first |

## Schema

| Table | Rows (approx.) | Primary key | Links to |
| --- | --- | --- | --- |
| `customers` | ? | id | - |
| `order_items` | ? | id | orders (order_id); products (product_id) |
| `orders` | ? | id | customers (customer_id) |
| `products` | ? | id | - |

## Example queries

### Orders with their customer

```sql
SELECT o.id, c.name, o.status, o.created_at
FROM orders o
JOIN customers c ON c.id = o.customer_id
ORDER BY o.created_at DESC
LIMIT 20;
```

### Order items with their product

```sql
SELECT oi.id, p.name, oi.quantity
FROM order_items oi
JOIN products p ON p.id = oi.product_id
ORDER BY oi.id
LIMIT 20;
```

### Count orders per customer

```sql
SELECT c.name, count(*) AS orders_count
FROM orders o
JOIN customers c ON c.id = o.customer_id
GROUP BY c.name
ORDER BY orders_count DESC
LIMIT 10;
```

### Latest customers

```sql
SELECT *
FROM customers
ORDER BY created_at DESC
LIMIT 10;
```

## Rules

- One SELECT per call. INSERT, UPDATE, DELETE, DDL, multiple statements and side-effect functions are refused by the server.
- Always add `LIMIT` (and `ORDER BY` when order matters). Results are capped at 200 rows.
- Call `describe_table` before querying a table you have not seen; do not guess column names.
- Prefer aggregates (`count`, `sum`, `GROUP BY`) over pulling raw rows when the user asks for numbers.
- Prefer the named query tools when they fit: they are reviewed and parameterized.
- If a valid query is refused because the parser cannot read it, simplify it or ask the user to add it as a named query.
